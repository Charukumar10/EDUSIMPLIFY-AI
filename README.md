# EduSimplify AI

## AI-Powered Personalized Learning Assistant

EduSimplify AI is a Generative AI-based educational assistant designed to simplify learning and help students prepare for examinations.

### Features
- Simple Explanation
- 2-Mark Answers
- 13-Mark Answers
- Multiple Choice Questions
- Lesson Summary
- Practice Quiz
- English and Tamil Language Support

### Technologies Used
- Python
- HTML
- CSS
- Generative AI
- IBM Cloud

### Project Objective
To make education easier, smarter, and more accessible through AI-powered personalized learning.
